# Sahar&Vosk — Telegram Bot для студий в Кудрово

## 📌 О проекте
Премиальный консьерж-сервис для автоматизации клиентского обслуживания, онлайн-бронирования в реальные слоты мастеров, удержания гостей и защиты репутации сети студий **Sahar&Vosk**.

- **Стек**: Python 3.11+, aiogram 3.x, aiosqlite (WAL mode), APScheduler (AsyncIOScheduler), aiohttp.
- **Часовой пояс**: строго `Europe/Moscow` (UTC+3).
- **Синхронизация**: прямая интеграция с CRM YCLIENTS API v1.
- **Управление контентом**: более 80 экранов и медиа управляются управляющей студии через `/admin` и таблицу `step_content` без правок кода.
